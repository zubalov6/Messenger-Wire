##Wire — Real-time Web Messenger
#Wire — это современный мессенджер для обмена сообщениями в реальном времени с поддержкой личных и групповых чатов, ролевой системой и гибким управлением чатами.

#🚀 Основные возможности
Аутентификация и авторизация: Безопасная регистрация и вход пользователей.

Управление чатами:

Создание и удаление личных (1-on-1) чатов.

Создание, настройка и удаление групповых чатов.

Система ролей: Разграничение прав доступа и возможностей пользователей внутри системы/чатов.

Real-time сообщения: Мгновенный обмен сообщениями без перезагрузки страницы благодаря WebSockets.

##🛠 Технологический стек
#Backend
Python / FastAPI — асинхронный веб-фреймворк для реализации REST API и WebSocket-соединений.

SQLAlchemy — ORM для работы с базой данных.

PostgreSQL — реляционная база данных.

#Frontend
React — библиотека для создания пользовательского интерфейса.

Vite — быстрая сборка и клиентский сервер разработки.

##Инструкция по запуску
backend:
1. Перейти в Messenger/
2. Активировать venv
.\venv\Scripts\activate
3. Установить зависимости
pip install -r requitements.txt
3. Запустить:
uvicorn app.main:app --reload

frontend:
1. Перейти в Messenger/frontend
cd frontend
2. npm install
3. npm run dev

База данных:
1. Установить PostgreSQL
2. Создать БД Messenger
3. Выполнить миграцию Alembic
alembic upgrade head
